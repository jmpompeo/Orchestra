# Repository instructions

Read `docs/agent-context.md` before planning or editing. It contains this
repository's commands, architecture, conventions, boundaries, risk tiers, and
validation sensors. Read `docs/harness-evolution.md` when it exists and the
work exposes a recurring agent or delivery failure.

Apply the user's global engineering workflow. This file and any nearer
`AGENTS.md` or `AGENTS.override.md` files take precedence for
repository-specific behavior.

When completed work reveals durable repository knowledge that cannot be
inferred cheaply from code, propose a small update to `docs/agent-context.md`.
Do not turn one-off incidents into permanent rules.
