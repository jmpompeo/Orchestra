# AI engineering workflow configuration

Portable personal defaults, project adapters, subagent definitions, and skills
for feature delivery and project-harness bootstrapping across Codex, Claude
Code, and Cursor. The primary distribution is the runtime-free `agent-harness`
.NET 10 CLI; cloning this private repository is only needed to develop or audit
the harness.

See [INSTALL.md](INSTALL.md) for setup, updates, project adoption, model
assignments, work/personal boundaries, and safe uninstall instructions.
